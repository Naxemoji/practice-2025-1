## Задание

Создать статический сайт проекта (HTML/CSS или Hugo) с уникальным дизайном и разместить исходный код на GitHub/GitVerse. Разработку вести через Git с осмысленными коммитами, а всю документацию писать в формате Markdown. На сайте реализовать 5 обязательных разделов: аннотация (главная), описание проекта, участники (с их вкладом), журнал прогресса (минимум 3 записи) и полезные ресурсы. Обязательно проиллюстрировать проект схемами, фото или видео.

## Вариативная часть задания

Разработать серверное приложение (интерактивного чат-бота) для платформы Discord с использованием среды выполнения Node.js и библиотеки Discord.js v14. Требуется реализовать систему обработки слэш-команд (Slash Commands): в качестве триггера выступает ввод пользователем предопределенной команды в текстовый канал. При отправке команды в реальном времени должно происходить её распознавание на стороне сервера и отображение в чате интерактивного ответа (Rich Embed сообщение). Приложение обязано обеспечивать интерактивное взаимодействие с появившимся интерфейсом — пользователь должен иметь возможность нажимать встроенные Message Components (кнопки) или выбирать опции в Select Menus. Инстанс бота должен быть корректно авторизован в API Discord через защищенный токен, устойчиво поддерживать WebSocket-соединение при изменениях состояния сети и использовать строгую типизацию намерений (Gateway Intents) для корректного отслеживания серверных событий.
